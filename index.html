One window for the frontline web.

Powerapp Frontline Workspace Shell puts Power Apps, Teams, or a second approved web app side by side in a native Windows app. Configure one file, commit, and GitHub Actions builds the installers.

From template to installer

1

Copy the template

Create your own repository. The Windows build workflow comes with it.

2

Edit config.json

Set the title, one or two pane URLs, the allowed domains, and the layout.

3

Commit

The push builds your MSI and NSIS. If no run appears, use Actions → Run workflow.

Let an agent set it up

Paste this into your coding agent. It handles the copy, the config, and the first build; you answer the questions about your apps.

Copy the open-source template at https://github.com/Spuds0588/Powerapp-Frontline-Workspace-Shell and help me turn it into a Windows desktop shell for my web apps. Read agents.md and config.json first. Ask me for the window title, the one or two app URLs, the domains they need, the sidebar side and width, and whether I want kiosk mode. Then update config.json and walk me through committing so GitHub Actions builds my MSI and NSIS. If no build starts, use Run workflow in Actions.
